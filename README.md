# Видеодомофон MDVR — исследование протокола и веб-плеер

Проект посвящён реверс-инжинирингу проприетарного потокового протокола
видеодомофона (мобильный видеорегистратор MDVR) и созданию веб-приложения
для живого просмотра видео в браузере.

## Состав каталога

| Путь | Описание |
|---|---|
| `docs/PROTOCOL.md` | Разбор бинарного протокола MDVR (главный документ) |
| `docs/ARCHITECTURE.md` | Архитектура веб-приложения VideoIntercom |
| `VideoIntercom/` | Blazor Web App (.NET 10) — живой просмотр в браузере |
| `toServer720.bin` | Бинарный handshake-запрос потока (500 байт, скопирован с оригинального клиента) |
| `fromServer720*.bin` | Дампы ответов домофона (исходные данные для анализа) |
| `ch00.h264`, `ch01.h264` | Извлечённые элементарные потоки H.264 обоих каналов |
| `frames/` | Кадры, декодированные из канала 00 (для верификации) |

## Краткая сводка

- **Устройство:** видеодомофон/MDVR `MDVR96NT_2_R`, адрес `192.168.31.150:9000` (TCP)
- **Протокол:** проприетарный бинарный; после handshake сервер шлёт смесь
  видео-пакетов двух каналов в псевдо-AVI обрамлении (`NNdcH264`)
- **Видео:** H.264 Annex-B
  - канал `00` — 704×576, ~1.25 fps, SPS/PPS в каждом IDR — **единственная
    реальная камера, рабочий**
  - канал `01` — формально 720p, 25 fps; **не содержит изображения** — вход
    второй (неподключённой) вызывной панели, цифровой мусор (доказательства —
    протокол §5.1); воспроизводится через серверный транскод как демонстрация
- **Приложение:** Blazor Server; фоновый сервис разбирает поток, HTTP-эндпоинт
  раздаёт кадры с честными длительностями, браузер играет через MSE (jmuxer);
  для канала 1 — серверный FFmpeg-транскод (`Ch1Transcoder.cs`)

## Быстрый старт

```bash
cd VideoIntercom
dotnet run --urls http://*:5244
# открыть http://localhost:5244
```

## Инструменты анализа

```bash
# живой дамп потока
cat toServer720.bin | timeout 20 nc 192.168.31.150 9000 > dump.bin

# извлечь H.264 канала 00 и декодировать кадр
ffmpeg -f h264 -i ch00.h264 -frames:v 1 frame.jpg

# проверить, что отдаёт веб-сервер
curl --max-time 5 http://localhost:5244/videofeed/0 | xxd | head
```
